# PawSeul


![첫번째 사진](https://github.com/user-attachments/assets/f09454d6-cbc5-4004-b85f-a68ec8c8fa2c)

반려견 건강정보 기반 펫커머스 플랫폼, **포슬(PawSeul)**

포슬은 **반려견의 유형에 맞게 세분화된 카테고리**를 통해, 우리 강아지에게 필요한 제품을 손쉽게 찾을 수 있도록 돕습니다. 또한 **반려견의 건강 상태와 식단 정보를 바탕으로 맞춤형 영양소와 제품을 추천**하여 주인의 건강 부담을 덜어주고, 반려견의 삶의 질 향상에 기여합니다.
